# Skill: TPO_M5_2.0

## 定位
TPO_M5 的改进版。选股**基础条件**与 TPO_M5 完全一致，仅两处不同，待逐步填充：
- 差异 1：选股排序/选法（TPO_M5 是"市值倒序后选第一只"，本策略要改进这一点）
- 差异 2：T-0 卖出规则（与 TPO_M5 不同）

## 选股基础条件（与 TPO_M5 一致，来源 `MarcoAPI/Update/SZ200Strategy.py::UPDATE_STRATEGY_TPO_M5`）
- 市值口径：`T-2` 日收盘价 × 流通股本，区间 **200 亿 ~ 1300 亿**
- `T-3`：首板放量涨停（`is_top==1` 且 `lian_ban==1` 且 `is_volume_up==1`）
- `T-2`：上涨、放量、未涨停（`is_up==1` 且 `is_volume_up==1` 且 `is_top==0`）
- `T-1`：收盘涨跌幅 `<= 3%`（含边界）、缩量（`is_volume_down==1`）、收盘价 `> MA5`
- 止损线：**-5%**（写入每行第 29 列，供回测使用）

## 待定项 1 —— 选股改进（替代 TPO_M5 的"市值排序后选第一只"）
TPO_M5 做法：满足基础条件后**按市值倒序**，取**第一只满足
"T-1 收盘 >= 预测 T-0 MA5 = (T-1*2 + T-2 + T-3 + T-4)/5"** 的，
若无满足者则当日空仓。
TPO_M5_2.0 要改进"市值排序后选第一只"这一排序/选法逻辑。
改进方向参考 `威科夫盘口解读方法_总结.md` 第十节（用"量价行为"作排序权重，替代纯市值）。
具体权重 / 规则待用户口述 → 填到 `tpo_m5_2_0.py::rank_select`。

## 待定项 2 —— T-0 卖出规则（与 TPO_M5 不同）
TPO_M5 的 T-0 卖出走 `Backtest` 内置口径：
涨停价 / 止损价(-5%) / 收盘价（或 `5m` 日内模式）。
TPO_M5_2.0 的 T-0 卖出规则不同，改进方向参考 `威科夫盘口解读方法_总结.md` 第十节
（放量滞涨=派发、有效跌破+反抽无力=确认卖点，替代固定涨跌幅止损）。
具体规则待用户口述 → 填到 `tpo_m5_2_0.py::t0_sell`。
（若实现自定义卖价，需配套改回测口径，暂以 TODO 占位。）
