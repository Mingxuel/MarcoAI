# 《威科夫盘口解读方法》核心总结

> 来源：Richard D. Wyckoff 以笔名 **Rollo Tape** 所著《**Studies in Tape Reading**》（1910）之中文译本/汇编《量价分析创始人威科夫的盘口解读方法》。

## 一、核心理念：盘口解读（Tape Reading）

- 价格是被人为操纵的结果；一切走势都可从「供需关系 + 参与者行为」找到解释。
- **读带 = 观察逐笔 / 分时量价行为**（早期为电报纸带打印的逐笔成交），判断买卖双方的相对力量与主力意图。
- 价格可以被瞬间操纵，**成交量最难伪造**——把目光从价格移到成交量上。
- **不逆"带"交易**：当带显示强劲需求时不做空，显示供应主导时不做多。
- 专注少数活跃标的，观察其"性格（behavior）"：吸筹 / 派发往往在量价细节里提前显露。

## 二、威科夫三大定律（所有判断的根）

1. **供求定律（Supply & Demand）**：需求 > 供应 → 价涨；供应 > 需求 → 价跌。用价量柱对比、VWAP 研判。
2. **因果定律（Cause & Effect）**：交易区间的"因"（积累 / 派发的力量）决定后续趋势的"果"；可用点数图（P&F）水平计数测算目标涨幅 / 跌幅。
3. **努力与结果定律（Effort vs Result）**：量价背离预警反转。例：大涨却高量小实体、无新高 = 努力无结果 = 派发前兆；大跌却低量、跌不动 = 供应枯竭 = 吸筹。

## 三、威科夫价格周期（Price Cycle，循环往复）

**积累（Accumulation）→ 拉升（Markup）→ 派发（Distribution）→ 下跌（Markdown）→ 回到积累**

## 四、吸筹结构（底部，主力低位隐蔽收集）

顺序：

1. **抛售高潮 SC**：大跌 + 巨量，散户恐慌卖出终点。
2. **自动反弹 AR**：SC 后价格轻松回升，买盘开始主导。
3. **二次测试 ST**：再探底，但成交量显著萎缩 → 抛压枯竭。
4. **Spring 震仓**：短暂跌破前低后迅速拉回，制造空头陷阱清洗最后浮动筹码。
5. **跳跃点 Jump Across the Creek**：放量突破盘整区间上沿 → 吸筹结束、上涨启动（**确认买点**）。

## 五、派发结构（顶部，主力高位转移筹码）

顺序：

1. **买入高潮 BC**：快速冲高 + 巨量，公众贪婪追买顶点。
2. **自动回落 AR**：BC 后价格轻易下滑，卖盘积聚。
3. **二次测试 ST**：反弹至前高附近但量缩 / 无法突破 → 需求不足。
4. **高价区放量滞涨**：实体短小甚至收阴但量异常放大 = 主力暗中派发。
5. **跌破支撑**：有效跌破派发区间下沿、反抽无力 → 控制权转空（**确认卖点**）。

## 六、量价信号速查表（看盘直接用）

| 信号 | 价格表现 | 成交量 | 市场含义 |
| :--- | :--- | :--- | :--- |
| 突然放量 + 大阳 | 大阳线 | 突放 | 主力推动 / 资金集中买入 |
| 放量 + 长上影 | 冲高回落 | 放量 | 高位派发 / 冲顶信号 |
| 缩量 + 跌不动 | 横 / 小跌 | 萎缩 | 无供应，可关注低吸 |
| 缩量 + 涨不动 | 横 / 小涨 | 萎缩 | 无需求，警惕回调 |
| 连续堆量 + 底部下影 | 底部震荡 | 持续 | 持续吸筹 |
| 连续堆量 + 顶部上影 | 顶部震荡 | 持续 | 持续派发 |
| 抛售 / 买入高潮 SC / BC | 急涨急跌 | 巨量 | 情绪极端点（顶 / 底） |
| 放量滞涨 | 实体短小 | 异常放大 | 派发典型迹象 |

## 七、震荡区（TR）的意义

- 长短周期都有 TR；分析 TR 内供需强弱可**预判突破方向**。
- TR 下沿附近「缩量跌不动 + 下影」= 支撑强（吸筹）；上沿附近「放量滞涨 + 上影」= 压力强（派发）。

## 八、盘口解读实操要点（来自原书）

- 读带判断买卖盘主导：连续主动性买单吃掉卖盘 = 需求强；反之供应强。
- 识别"最后一跌 / 最后一涨"的耗尽特征（SC / BC）。
- **聪明钱（Composite Man）行为**：利用公众心理（追涨杀跌、信利好传言、缺耐心）反向收集 / 派发。
- 复盘原则：多看「无供应 / 无需求」测试，少追突破；突破需放量确认。

## 九、买卖点与止损（可直接落规则）

- **买（布局）**：吸筹阶段 ST 缩量或 Spring 震仓时提前关注；**确认买点 = 跳跃点放量突破上沿**。
- **卖（警示）**：高价区放量滞涨即警示；**确认卖点 = 有效跌破派发区间下沿且反抽无力**。
- **止损**：每笔必设止损；以区间边界 / 结构破位为止损依据，控制单笔亏损。

## 十、与 TPO_M5_2.0 的衔接（供选股 / 卖出改进参考）

### 改进"市值排序选股"（`rank_select`）
- 不应仅按市值倒序取第一只。结合威科夫：在 T-1 候选中，**优先选择量价显示"需求恢复 / 供应枯竭"的标的**——
  - T-1 缩量小跌或止跌（无供应）、且处于相对低位 TR 后段 → 加分；
  - T-1 放量滞涨 / 高位堆量（派发相）→ 扣分 / 剔除。
- 用**量价行为作为排序权重**，而非单纯市值。可参考 `因果定律`：T-1 之前已有充分"因"（缩量吸筹结构）者优先。

### 改进"T-0 卖出"（`t0_sell`）
- 沿用「努力与结果」与「放量滞涨 = 派发」信号：
  - 盘中若所选股出现**放量长上影 / 冲高回落（无需求）**，或**跌破当日结构支撑且反抽无力**，按威科夫确认卖点逻辑提前离场；
  - 以"有效跌破 + 反抽无力"替代固定涨跌幅止损，更贴合主力行为。
- 买入日若带显示强劲供应（持续主动性卖盘、无需求反弹），则放弃当日买入或即刻了结。
