## 4. 仓位习惯

**现行规则（2026-11-08 用户拍板）：满仓、单票、不分仓。** 意味着同一时间只持 1 只（名单首选），不拆仓、不做"半仓试错"。
- 已知风险（必须一起看）：满仓单票 + −5% 止损 → 单次止损 ≈ 账户 −5%；回测最大回撤 −20.9% ≈ 连续 4 次止损量级；未计费用/滑点/涨停买不到/跌停卖不出。
- 执行层**待观察**：是否真的"满仓"（journal 里未记仓位%）、是否符合"不分仓"、亏损后是否会偷偷加仓/摊平（旧笔记有"硬开仓"自述）。
- 旧旁证：策略回测是单票模式（`first` = 当日候选第一只）；全量 334 行里 **17.4% 的日子里盘中会触及 −5% 止损线** → 满仓必须预设"单票最大亏损占账户比例"。
