# 六维评分卡（RUBRIC）

> 维护者：小小A（xiao-xiao-a）｜版本 v1.10｜2026-11-08
> 用途：把"感觉你进步了"变成可核验的分数。**每维 1~5 分，只认证据，不认印象。**
> 配套：`USER_PROFILE.md`（画像/证据）、`PLAYBOOK.md`（风格判断标准）、`REVIEW_YYYY-Www.md`（周评）。

## 1. 六维定义与评分锚点

### 1.1 选股逻辑（Stock Selection）

| 分 | 锚点 |
|---|---|
| 1 | 没有明确条件；"看着好""感觉会涨"；选股条件每天不一样 |
| 2 | 有条件但不可复现（条件互相矛盾、或看结果反推）；说不清"为什么是这只" |
| 3 | 有稳定、可复现的选股条件，且能说清逻辑；但不区分环境，任何行情都同一套 |
| 4 | 条件可复现 + **分环境启用/关闭**；能指出"这套条件在什么行情里失效"（有数据或样本支撑） |
| 5 | 选股逻辑形成体系：环境判断 → 风格选择 → 选股条件，三者一致；能用**样本外**数据说明逻辑没退化 |

### 1.2 买卖纪律（Execution Discipline）

| 分 | 锚点 |
|---|---|
| 1 | 无买点/卖点/止损；全凭盘中感觉 |
| 2 | 有卖价"预期"但无规则；无止损；"可买可不买"仍下单；无成交记录 |
| 3 | 买点、卖点、止损**三个价都写下来**，多数交易能按记录执行；有成交记录可核验 |
| 4 | 每个价格有**触发条件**（不是价位）；连续 ≥10 笔执行率 ≥80%；止损必执行 |
| 5 | 买卖规则与风格绑定（不同风格不同卖法）；规则可被回测/日志**证伪**；执行偏差可被自己识别并修正 |

### 1.3 仓位管理（Position Sizing）

| 分 | 锚点 |
|---|---|
| 1 | 无仓位概念；凭感觉满仓/梭哈；无记录 |
| 2 | 有"仓位"意识但不设上限；亏损后加仓/补票；单票占比未知 |
| 3 | 有单票上限、有当日/当月最大亏损线；能记录仓位 |
| 4 | 仓位与**环境 + 确定性**挂钩（环境差降仓、信号强加仓），有公式或明确规则 |
| 5 | 有完整的头寸管理：单票上限 × 相关性 × 环境系数；回撤控制优先于收益目标；有历史最大回撤/连续亏损记录 |

### 1.4 情绪控制（Emotional Control）

| 分 | 锚点 |
|---|---|
| 1 | 频繁冲动单；亏损扛单/加仓摊平；连续亏损后报复性交易 |
| 2 | 有冲动/硬开仓记录；事后合理化（"其实不买也可以"两头都说）；边界单消耗大量注意力 |
| 3 | 极少冲动单；能识别"今天状态不好"并降操作；错误会记下来但不一定改 |
| 4 | 有计划外单识别机制；连续亏损能主动停手；情绪状态有自查清单 |
| 5 | 情绪与决策分离：有固定的"当日状态→仓位/是否交易"规则；复盘里能区分"判断错"和"执行错" |

### 1.5 复盘质量（Review Quality）

| 分 | 锚点 |
|---|---|
| 1 | 不写；或只写"今天亏了/赚了" |
| 2 | 只复盘"盘面"（为什么涨跌），不复盘"自己"（成交/仓位/止损/错误）；无盈亏数字 |
| 3 | 有操作+买卖点+盈亏+错误归因四件套；能对得上账 |
| 4 | 有"计划 vs 实际"对照；错误按类归档并有重复错误统计；次日计划具体到条件 |
| 5 | 复盘能产出**规则级**结论（写进 PLAYBOOK 并回测/验证过）；能识别自己的模式化错误并设定改进实验 |

### 1.6 风格一致性（Style Consistency）

| 分 | 锚点 |
|---|---|
| 1 | 每天换风格；同一只票一会儿超短一会儿波段；自述与实际完全不符 |
| 2 | 自述"超短线"但工具/数据/持仓周期指向另一种；或两套手法混跑无法归因 |
| 3 | 有**一个明确的当前主风格**，且操作、工具、数据一致；偶尔漂移能自我发现 |
| 4 | 主风格稳定 ≥1 个月；能说清"为什么是我这个风格"（性格/时间/资金）；风格漂移有预警 |
| 5 | 有 1 主 + 1 辅风格的**切换规则**，与环境判断绑定；不同风格用不同账户/仓位隔离 |

## 2. 打分规则（防止自欺）

1. **证据优先**：每个分数必须能指到具体日志/数据；无证据 = **1 分**并注"无证据（未观察）"。
2. **样本门槛**：涉及"胜率/执行率"的结论，样本 <5 笔不单独评（标注"样本不足"），滚动到 5 笔再评。
3. **不看盈亏看过程**：赚钱的单子如果违反规则，该项**扣分**；亏钱但严格执行规则，**不扣分**。
4. **不许跳级**：单周最多升 1 分（除非有 ≥10 笔干净样本），防止"一篇好日志给 5 分"。
5. **降分要写原因**：任何降分必须在周评里写"哪条证据导致降分"。
6. **评分频率**：每篇日志摘要后做增量记录（只在有变化的维度上改）；**每周五出一份正式周评分数**（`REVIEW_YYYY-Www.md`）。
7. **初评只给一次**：v1.0 的初评（下表）在积累 ≥10 笔真实交易后作废重评。
8. **证据只认 `SUMMARY_SCHEMA` 的段落**：评分输入 = `journals/summaries/<日期>.md` 的 §3 逐笔表 / §4 盈亏 / §5 纪律与错误 / §2 环境；**用户原文只在其被 schema 摘录时使用**（理由原话、值得回看的一句）。
9. **示例/虚构日志不计分**：`journals/samples/` 与 `summaries/*-sample.md` 只用于流程演练，不进分数、不进画像。
10. **缺口即降置信度**：摘要 §9「缺失项清单」中缺口 ≥50% 的维度 → **按"无证据"处理（标灰按 1 分，不额外降级）**，并在留痕表注明"缺口"；连续 3 篇都缺同一字段 → 该字段升级为给用户的"必填红线"。
11. **代码缺失 = 不可对账**：逐笔表没 6 位代码时，涉及"实际成交价 vs 行情最高/最低"的判定一律不写结论（我能做的只有"用户自述层面"的评分）。
12. **卖法版本参与归因**：`SUMMARY_SCHEMA` §3 已有「卖法(B+/旧/未标注)」列。①标"B+"的笔才参与"是否按 B+ 执行"的判定；②标"旧"的笔归因到旧卖法，不混入 B+ 评价；③标"未标注"的笔**不猜、不归因**（只计入纪律/复盘维度）；④混用日逐笔归因，周评里单列"卖法切换日"。
13. **补写/历史日志不自动视为"旧"（与小志 2026-11-04 约定的边界）**：2026-11-04（B+ 生效）之前日期的日志，**不按日期回填卖法版本**——只有用户自述/日志明确写了卖法才标"旧"，否则一律"未标注"；我按规则 12 的 ③ 处理（不猜、不归因）。目的：避免把"补写"误判成"旧卖法混用"，污染周评。
14. **数据侧补记的用法**（小志 11-06 起提供，如 11-03/11-04 两笔）：①**可以**用于事实核对（买卖价、止损是否触发、卖法行为是否与规则一致）；②**不进** TAGS 计数、**不进**"纪律/情绪"评分（没有用户自述，无法判断当时意图）；③卖法版本一律按时间：**B+ 决定（2026-11-04 17:07）之前的交易标"未标注"**，即使行为与 B+ 分支巧合一致也不得标 B+；④可用于"个案示意"（如"若按 B+ 会怎样"），但 n=1 不能当验证、不能当收益承诺。
15. **名单可用性参与"计划内/抢跑"判定**（`SUMMARY_SCHEMA` §9 固定字段，2026-11-06 起）：`可用` → 可正常判定"按计划买"；`不可用`/`无名单` → 该笔的"依据"必须单列（自主决策/旧名单），**不得把工具延迟或名单缺失算成用户"计划外/抢跑"扣分**；"抢跑"只针对"名单可用/自主计划已定时，仍偏离自己的执行窗口"的情形。
    - **时间边界（2026-11-06 深夜 Lead 通报 task-46 修复）**：11-06 记"不可用"属历史事实（旧版 4304s）；修复后 14:40 触发/14:45 前就绪/实测 2~4s → **自 2026-11-09 起默认按"可用"归因**，11-09 之后再以"工具延迟"为由不成立；11-07/11-08 非交易日。若 11-09 实测调度仍未就绪，再按"不可用"处理并记入周评。
16. **环境口径版本参与归因（2026-11-08 起 B+ 环境多次升级，最终版 = S6）**：①**现行口径 = S6 四状态打分**（沪深300>日线MA60 +1、创业板指>日线MA60 +1、中证银行≤日线MA60 +1 → score 0~3）；②旧口径（7 宽基宽度 +302.7%、3 指数宽度 +286.7%、S3 +287.1%、3 指数二值 +326.6%）**只作对比、不混用**；③11-08 之前的历史交易按"当时口径"记录，不回溯改判。
17. **四状态（S6）引用口径，别与前几版混淆（2026-11-08 新增）**：①引用 B+ 数字必须写"**S6 + 137 笔 + 日期**"，其他版本标注"上一版/对比"，**禁止把不同版本的数字相加或比较换代差**；②判定分支必须按 S6：涨停价卖 > −5% 止损 > **score≥2 → 14:55** / **score==1 → 10:00 宽度（沪深300+创业板指"都红"才抗，**不含银行**）** / **score==0 → 10:00 卖** / 数据不足 → score 不可用 → **回退满仓+14:55**；③**仓位 = 满仓单票不分仓**，评分时"仓位管理"看用户是否真的满仓/是否违反不分仓（不回测推断）；④旧文档里的"好环境/差环境"表述一律换算成 score 状态再引用，避免把"状态"与旧二元标签混淆。

## 4. 晋级标准（L1 → L5）

| 阶段 | 名称 | 硬条件（全部满足） | 对应分数 |
|---|---|---|---|
| **L1** | 记录者 | 有复盘日志；能说清自己每天看了什么 | 选股 ≥1，其余 ≥1 |
| **L1.5** | 半闭环 | 连续 ≥10 个交易日有日志；有买入记录 | 复盘 ≥2 |
| **L2** | 可核验的执行者 | 连续 ≥10 笔**同时具备**：买价/卖价/仓位/止损价 + 盈亏；执行率可算 | 买卖纪律 ≥3；复盘 ≥3 |
| **L3** | 体系者 | ①固定主风格 ≥1 个月不漂移；②规则可证伪（能说出"什么情况下我错了"）；③错误有归类且重复错误 <2 类；④月回撤有上限且未击穿 | 六维均 ≥3 |
| **L4** | 进阶者 | ①有环境择时规则（做不做/做几成）；②主风格 ≥2 个月正期望（按自己的账，不按回测）；③有周评/月评并持续 ≥6 周；④能把"判断错"和"执行错"分开统计 | 六维均 ≥4，其中买卖纪律 ≥4 |
| **L5** | 专家 | ①1 主 + 1 辅风格的切换规则；②≥6 个月可核验正期望 + 回撤可控；③能把自己的体系讲清楚到可被他人复现；④能把新经验反写进 PLAYBOOK 并用数据验证 | 六维均 ≥4.5，选股/纪律/仓位 =5 |

> **降级规则**：连续 2 周出现"无记录/无止损/风格漂移"任一 → 该维度回落到上一档；不是惩罚，是提醒"体系还没稳住"。

## 5. 分数 → 处方（本周唯一改进点怎么选）

按**杠杆**排序（不是按分数最低）：

1. **复盘质量 <3** → 先做记录闭环（记 4 个数：买价/卖价/仓位/止损价）。**杠杆最高**：一项改动同时喂饱纪律/仓位/情绪三维的证据。
2. **买卖纪律 <3** → **卖法已定（2026-11-04 起 = B+，见 `PLAYBOOK.md` §2.12）**，所以本周只练"执行"：开仓前写止损价（成本×0.95）、按 B+ 分支记录"应该怎么卖 / 实际怎么卖"，别临场改卖法。
3. **仓位管理 <2** → 定单票上限（例如 ≤30%），写在日志首页，先遵守 2 周。
4. **情绪控制 <3** → 设"计划外单 = 当日停手"规则 + 记下触发原因。
5. **风格一致性 <3** → 明确"当前主风格是什么"，并回答"你要隔日套利还是打板/接力"；选定后 1 个月内不换。
6. **选股逻辑 <3** → 才去优化选股（否则是在优化一个执行不了的体系）。

**硬规则**：每周只推 **1 条**改进建议（周评里写死），多了等于没推。
